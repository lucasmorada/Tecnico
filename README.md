Up Life Technician Directory

A simple technician directory developed as a complementary feature for the Up Life Educacional website.

About

This project provides a simple interface for users to browse available technicians and contact a selected professional directly through WhatsApp.

The system generates a personalized WhatsApp message based on the technician selected by the user, making the contact process faster and more convenient.

The page was developed to be integrated into the existing Up Life website and complement its online education platform.

Features
Technician listing
Individual technician selection
Dynamic WhatsApp contact links
Personalized pre-filled WhatsApp messages
Responsive interface
Integration with the existing Up Life website
Technologies
HTML5
CSS3
JavaScript
How It Works
The user accesses the technician directory.
Available technicians are displayed on the page.
The user selects the technician they want to contact.
JavaScript generates a personalized WhatsApp message containing the selected technician's name.
The user is redirected to WhatsApp with the message ready to send.
Purpose

The project was developed to improve the communication flow between users and technicians while providing a simple and accessible interface integrated into the Up Life platform.

Integration

This page was developed specifically for Up Life Educacional and integrated into its existing website.

The main Up Life platform provides online courses and professional training across multiple areas, including technology, management, engineering, and other professional fields.
